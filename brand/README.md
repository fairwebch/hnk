# HNK Kroatien Schwyz — Visual Brand System v1.0

Status: **Approved foundation / implementation in progress**

This folder is the source of truth for HNK Kroatien Schwyz visual communication across web, social media, print, event signage and Canva templates.

## Authority order

1. `BRAND_GUIDE.md`
2. `DESIGN_RULES.md`
3. `TOKENS.md`
4. `AI_INSTRUCTIONS.md`
5. Current production website design system
6. Approved HNK assets
7. Event-specific approved creative direction

If an old design reference conflicts with current production tokens, current production code wins.

## Core direction

**Premium Editorial Sport**

The identity should feel athletic and energetic, but also controlled, modern, authentic and professional.

The brand must not fall into generic AI/Canva football-flyer aesthetics.

## Workflow

For every new visual:

1. Brief
2. Check missing information
3. Propose one best visual direction
4. Danijel approval
5. Design
6. Brand review
7. Export/adaptation

No brand exception is introduced without Danijel's approval.

## Files

- `BRAND_GUIDE.md` — brand foundation and creative direction
- `DESIGN_RULES.md` — strict do/don't rules
- `TOKENS.md` — colors, typography and visual tokens
- `AI_INSTRUCTIONS.md` — reusable instructions for ChatGPT / Claude / other AI design workflows
