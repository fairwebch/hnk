# HNK Kroatien Schwyz — Design Rules v1.0

These rules are operational and intentionally strict.

## Always

- Use the official HNK logo assets.
- Use only Barlow and Barlow Condensed.
- Keep the visual direction premium, editorial and sports-focused.
- Prefer real HNK photography.
- Keep hierarchy clear: event name + date first.
- Keep copy minimal on primary flyers.
- Use red as an accent, normally about 5–15% of the composition.
- Use sharp corners.
- Use a dynamic editorial grid.
- Use medium negative space.
- Keep sponsor logos in a clean dedicated zone.
- Recompose for each format instead of auto-cropping.
- Ask for missing event information instead of inventing it.

## Never

- AI-generated players, supporters or club members.
- Generic AI football people.
- Generic stadium backgrounds as a default solution.
- Flaming footballs.
- Lightning effects.
- Neon sports glow.
- Blue/red light streaks.
- Gaming aesthetic.
- Gold 3D typography.
- Chrome typography.
- Heavy lens flare.
- Large national flags as decoration.
- Large checkerboard backgrounds.
- Checkerboard as the main visual.
- Random additional fonts.
- Rounded app-style cards as the default visual language.
- Excessive drop shadows.
- Excessive texture.
- Excessive skew/diagonal elements.
- Visual clutter to compensate for a weak photo.
- Generic Canva sports-template aesthetics.

## Checkerboard rule

The Croatian checkerboard is a micro-signature only.

Use it as a tiny strip, corner, separator or subtle pattern detail.

If it is immediately dominant, reduce or remove it.

## Diagonal / skew rule

Use diagonal or skew treatments as the primary signature language, but normally limit them to 1–2 significant elements per composition.

Reference angle behavior comes from the website `skewX(-8deg)` system.

## Photography rule

Allowed:
- crop
- contrast
- selective darkening
- subtle grain
- masking
- layering
- restrained navy/red toning

Not allowed:
- replacing real people with generated people
- altering a person's identity
- unrealistic blockbuster compositing
- effects that make a real HNK moment look synthetic

## Text over photography

Controlled overlap is allowed.

Do not cover faces, key action, the ball when important, or essential visual information.

Use gradient/selective darkening before using heavy shadows.

## Logo rule

Official event/tournament/invitation: primary logo clearly visible.

Editorial/social: logo may be more discreet when the composition already reads clearly as HNK.

Secondary mark is permitted only in approved secondary-use contexts.

## Color rule

Primary red: `#D8232F`
Primary navy: `#0D1B33`
Paper: `#F5F6FA`

Do not introduce new colors without approval.

Unused website tokens such as royal blue are not automatically approved for campaign use merely because they exist in code.

## Typography rule

Display: Barlow Condensed, typically 700–800 for high-priority event typography.

Body/info: Barlow 400–700.

Large event titles are generally uppercase.

## Copy rule

Primary flyer content should normally be limited to:
- event name
- date
- time
- location
- CTA
- web/contact if required

Do not turn a flyer into a brochure.

## Language rule

Choose language based on audience.

For larger public events, separate HR and DE versions are preferred.

Use Swiss German orthography in German copy.

## Sponsor rule

- dedicated sponsor area
- equal optical logo size
- no sponsor logo may visually overpower the event title unless required contractually
- keep sufficient spacing around sponsor marks

## Canva rule

Editable fields:
- text
- date/time
- photo
- sponsor logo

Locked fields:
- grid
- fonts
- brand colors
- logo placement
- spacing
- skew logic
- signature elements
- sponsor-zone structure

## Quality gate

Before approval, ask:

1. Does it look like HNK?
2. Does it feel premium?
3. Does it still have sports energy?
4. Is the hierarchy instantly clear?
5. Is red still an accent?
6. Is the checkerboard subtle?
7. Are diagonals/skews controlled?
8. Is the photography authentic?
9. Can anything be removed without losing the message?
10. Does it look like a generic AI/Canva football flyer?

If answer 10 is yes: simplify.

## Exception rule

No exception is self-approved.

Any deliberate deviation from these rules requires Danijel's explicit approval before final design.
